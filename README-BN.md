# BD Smart Vehicle — Android Starter Demo

এটি একটি প্রাথমিক Android Studio প্রজেক্ট। এতে:
- ফোনের ক্যামেরা দিয়ে ছবি তোলা
- Google ML Kit Text Recognition দিয়ে ছবির লেখা পড়া
- OCR-এ পাওয়া লেখার মধ্যে সম্ভাব্য নম্বর/সংখ্যা খোঁজা
- নমুনা (কাল্পনিক) ডেটা থেকে ডেমো ফলাফল দেখানো

## কী এখনো নেই
- BRTA/পুলিশ/সরকারি ডেটাবেসের লাইভ সংযোগ
- দেশের সব গাড়ির ডেটা
- নিশ্চিত বাংলাদেশি নম্বরপ্লেট পার্সার
- স্বয়ংক্রিয় জরিমানা বা আইনগত সিদ্ধান্ত
- সার্ভার, লগইন, মালিকের ব্যক্তিগত তথ্য

## চালানোর পদ্ধতি
1. কম্পিউটারে Android Studio ইনস্টল করুন।
2. এই ফোল্ডারটি Android Studio-তে Open করুন।
3. Gradle sync সম্পন্ন করুন।
4. Android ফোন USB debugging দিয়ে যুক্ত করুন।
5. Run চাপুন এবং Camera permission দিন।

প্রথমবার Gradle dependencies ডাউনলোড করতে ইন্টারনেট লাগবে।

## নিরাপত্তা ও আইন
বাস্তব যানবাহনের রেকর্ড, মালিকের পরিচয়, বকেয়া/মামলা/চুরি সংক্রান্ত তথ্য কেবল সংশ্লিষ্ট কর্তৃপক্ষের লিখিত অনুমোদন ও নিরাপদ API-এর মাধ্যমে ব্যবহার করতে হবে। সাধারণ ব্যবহারকারীদের জন্য কেবল আইনসম্মতভাবে প্রকাশযোগ্য সীমিত ফলাফল দেখাতে হবে।
